# 検品画像一括処理スタジオ（写真保管庫）

中古マテハンの検品写真を、取り込み → 加工 → 確定 → 書き出しまで一括で処理する単一HTMLアプリ。
ビルド不要。`index.html` がアプリ本体そのもの。

現在 **β版（v0.9.0-beta）**。

---

## 開き方

| 方法 | できること |
| --- | --- |
| `index.html` をダブルクリック | 基本機能はすべて動く。**保存先フォルダ連携だけ使えない**（ブラウザのセキュリティ制限） |
| GitHub Pages のURL | 全機能が使える |

推奨は Chrome または Edge の最新版（パソコン版）。

---

## 機能

**取り込み**

- 画面のどこにでもドラッグ＆ドロップ可能（フォルダごと落とすとサブフォルダも再帰的に走査）
- 「ファイル選択」「📁 フォルダ選択」ボタンからも取り込み可
- 読み込めなかった場合は、ブラウザから何が渡されたかを診断ウィンドウに表示する

**加工（4モード）**

1. **選択・移動** — ホイールで拡大縮小（カーソル位置を基準に寄る）、ドラッグで移動、ダブルクリックで等倍に復帰
2. **背景暗化** — 商品を楕円で囲み、外側を暗くする
3. **名前消し** — ブラシで塗りつぶし。スポイトで周囲の色を取得できる
4. **矢印・寸法** — 片方向／双方向の矢印。他の矢印と平行になると吸着。
   **🎯 色で幅を自動計測**: 商品の上をクリックすると、その色を基準に左右の境界を検出し、水平の双方向矢印を自動配置する

**整理・書き出し**

- フォルダ単位で分類。写真1枚ごとに個別の名前を付けられる（付けない場合は「フォルダ名＋連番」で自動採番）
- 確定した写真は 200KB 以下へ自動圧縮
- 📦 ZIP一括DL / 💾 接続フォルダへ直接書き出し

**AI 自動判別**

- Gemini API キーを設定すると、1枚目の写真の養生テープの手書き文字や形状から商品名を判別し、フォルダ名を自動設定する
- キーは各利用者のブラウザ内（localStorage）にのみ保存される。**このリポジトリにキーは含まれない**

## データの保存場所

写真データは **利用者のブラウザ内（IndexedDB）にのみ** 保存される。サーバーには一切送信されない。

> **注意**: ブラウザの保存領域はURL（オリジン）ごとに分かれている。
> `file://` で開いた場合と GitHub Pages のURLで開いた場合では**別々の保管庫**になり、データは共有されない。

外部への通信は次の2つだけ。どちらも利用者が明示的に操作した時のみ発生する。

| 宛先 | 用途 | 発生条件 |
| --- | --- | --- |
| `generativelanguage.googleapis.com` | Gemini による商品名の自動判別 | APIキーを設定し、自動判別をONにしている時 |
| `www.googleapis.com` | Google ドライブへのアップロード | 「☁️ Drive一括同期」を押した時 |

## バックアップ

`BACKUP.bat` をダブルクリックすると、`バックアップ/` フォルダへ日時付きで世代が保存される。
Git の履歴と役割が重複するため、このフォルダは `.gitignore` で除外している。

## 開発メモ

**バージョン表示** — 画面右上に表示中のバージョンが出る。「修正したのに変わらない」時は、ブラウザキャッシュか実装漏れかをここで切り分ける。**中身を変更したら `index.html` 冒頭の `APP_VERSION` / `APP_BUILD` を必ず更新すること。**

**座標系** — 加工用キャンバスは常に 1200×1200。状態はすべてこの座標系で保持しているため、表示倍率に関係なく書き出し結果が一致する。

**保存の重さ** — ドラッグやホイール操作の最中は保存を行わず、操作が止まってから 400ms 後にまとめて書き込む。毎フレーム保存すると全写真をデータURL化するため実用にならない。

### 既知の課題

- **IndexedDB の容量** — 元画像をデータURLのまま、全写真を1レコードに詰めて保存している。数十枚で容量超過する。Blob 化と写真1枚1レコードへの分割が必要（次の作業項目）
- **JSZip が CDN 依存** — オフラインや制限のあるネットワークでは ZIP 書き出しが失敗する。自前配置が望ましい
- **HEIC 非対応** — ブラウザがデコードできないため取り込めない。取り込み時にその旨を案内している
